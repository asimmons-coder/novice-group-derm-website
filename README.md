# Novice Group Dermatology

Public marketing site for Novice Group Dermatology in Bloomfield Hills, Michigan.
Next.js 16 App Router, Tailwind CSS v4, Framer Motion.

Practice facts live in src/lib/site.ts. Do not invent NPIs, review counts,
testimonials, booking URLs, or analytics IDs. Insurance is the 12 plans listed
there. Mohs is coordinated off-site. There is no patient portal.

Optional env: NEXT_PUBLIC_BOOKING_URL and NEXT_PUBLIC_GA_ID. Leave unset without a real value.

Deployed on Vercel.
